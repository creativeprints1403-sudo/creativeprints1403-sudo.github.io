Privacy policy

Last updated: 29 October 2026

The Hours Saved publishing tool is a private tool used only by the owner of the Hours Saved YouTube channel. It is not offered to the public.

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What Google data the tool uses

With the channel owner's permission, the tool uses Google APIs to upload video files the owner created to the owner's own Google Drive (only files the tool itself created) and to the owner's own YouTube channel, and to set titles, descriptions, thumbnails and captions on those videos.

What it does not do

The tool does not read, collect, sell or share any personal data, viewer data or other files. It does not use Google user data for advertising or to train AI models. Data is not transferred to anyone else.

Storage and deletion

No cookies or tracking are used. The access token is stored as an encrypted secret in the owner's private GitHub repository. The owner can revoke access at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube uploads are also subject to the YouTube Terms of Service and the Google Privacy Policy.
