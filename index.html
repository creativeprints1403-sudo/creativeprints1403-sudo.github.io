Hours Saved

Hours Saved is a YouTube channel with short, practical tutorials on AI tools that save you time at work.

This site also hosts the policies for the channel's own video publishing tool, which the channel owner uses to save finished videos to their own Google Drive and YouTube account.

The tool uses YouTube API Services to upload each week's videos to the channel as private, scheduled videos, so the owner can review them in YouTube Studio before they go public. It is used only by the channel owner.
